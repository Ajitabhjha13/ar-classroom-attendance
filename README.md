# AR Classroom Seating & Attendance System

A web-based classroom seating and attendance system with real-time updates and an AR-style 3D room visualization.

## Features
- Admin dashboard with live stats, interactive seat map, attendance log, and CSV export
- Student check-in portal with real-time seat selection
- AR-styled 3D classroom visualization
- QR code generation for quick student check-in access
- Real-time updates across all views via Socket.io

## Tech Stack
- **Backend:** Node.js, Express, Socket.io
- **Frontend:** HTML, CSS, JavaScript, A-Frame (3D/WebXR)
- **Data:** In-memory simulation (MongoDB planned for future)
- **Utilities:** qrcode (npm package)
