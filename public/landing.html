Core Features

Everything attendance.
Nothing manual.

A complete WebXR system that works on any modern smartphone browser. No app store, no installation.

📷

QR Marker Anchoring

Place a printed QR in each room. Students scan it and instantly see the seat map overlaid in AR on their camera feed.

AR.js + A-Frame
🔥

Live Seat Heatmap

Color-coded real-time seat grid. Green = available, purple = occupied, amber = reserved. Updates instantly via WebSocket.

Socket.io
🤖

Face Proximity Detection

TensorFlow.js detects the student's face in-browser. If confidence >85%, attendance is auto-marked with zero interaction.

TF.js BlazeFace
📊

Admin Analytics Dashboard

Faculty sees per-room occupancy, weekly trends, low-attendance alerts, and can export CSV reports in one click.

Real-time
🔐

Role-Based Auth

Separate flows for faculty and students. bcrypt password hashing, express-session, protected API routes.
